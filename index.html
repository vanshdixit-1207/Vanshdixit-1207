WEB APP • FULL STACK • QR ATTENDANCE

QR-Based Student Attendance Management System

A complete web-based attendance platform designed to make student attendance fast, secure and easy to manage using temporary QR codes.

01
OVERVIEW

The system allows authorized users to manage students, generate and scan QR codes, record attendance and view attendance history through a responsive Liquid Glass interface.

KEY FEATURES
  • Role-based authentication and access control
  • Temporary QR generation with expiry
  • QR scanning with session validation
  • Duplicate-scan prevention
  • Live attendance count and history
  • Reports and attendance analytics
  • Responsive UI with smooth animations
  • Input validation and security checks
